Create the access code

You do this once. Everything happens on this computer. Nothing is sent anywhere.

  1. Press Suggest a code, or type your own code of four or more words.
  2. Write the code on paper. Type it again below.
  3. Press Create key.json. Your browser downloads the file.

  1. Upload key.json to the site’s GitHub repository.
  2. Send the same key.json to Claude, so it can lock the month file. Never send the code.
  3. Share the code only in person or by phone. Close this page.

Capital letters and extra spaces don’t matter when they type it.
